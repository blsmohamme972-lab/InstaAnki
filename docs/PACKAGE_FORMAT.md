# صيغة حزم المحتوى (Pack Format v1)

> هذه الوثيقة هي **العقد** بين GPT (الذي يصنع المحتوى) والتطبيق. أي حزمة تلتزم بها وتنجح في أداة التحقق ستعمل في التطبيق.
>
> - المخططات الدقيقة (JSON Schema): [`schema/`](../schema)
> - أداة التحقق: [`tools/validate_pack.py`](../tools/validate_pack.py)
> - حزمة مثال كاملة: [`examples/sample-pack/`](../examples/sample-pack)

---

## 1. البنية

```
cardio-basics-001-v1.zip
├── pack.json                          ← بيانات الحزمة (في جذر الـ ZIP مباشرة)
└── reels/
    └── cardio-heart-chambers-001/     ← اسم المجلد = id الريل
        ├── reel.json                  ← الـ timeline والمناطق والأسئلة
        ├── transcript.json            ← توقيت كل كلمة في الصوت
        ├── audio.opus                 ← التعليق الصوتي
        └── img/
            └── heart.svg
```

## 2. القواعد الذهبية

1. **لا نصوص داخل الصور.** التسميات يرسمها التطبيق من `regions.label`، حتى يستطيع إخفاءها في الأسئلة.
2. **المخططات بصيغة SVG** مرسومة بالكود. كل جزء قابل للسؤال عنه يكون `<g id="...">`، وتشير إليه المنطقة بـ `svgId`. هذا يعطي دقة كاملة بدون تخمين إحداثيات.
3. **SVG آمن:** لا `<script>`، ولا `on...=`، ولا `<foreignObject>`، ولا روابط خارجية.
4. **كل الأزمنة بالثواني** من بداية ملف الصوت، وبدقة منزلتين عشريتين.
5. **الإحداثيات نسبية من 0 إلى 1** بالنسبة لعرض الصورة وارتفاعها (لغير SVG).
6. **المعرّفات ثابتة للأبد.** لتصحيح ريل: نفس `id` و`revision` أعلى، فتبقى الجدولة محفوظة.
7. **كل سؤال مربوط بمقطع يشرح جوابه** (`explain`). هذا المقطع هو ما يُعاد عند الخطأ.
8. **ابنِ الـ cues على توقيت الكلمات** وليس بالتقدير: الحركة تبدأ عند `s` الكلمة المقصودة.
9. **تحقّق قبل التسليم:** `python3 tools/validate_pack.py <zip>`، ولا تسلّم حزمة فيها أخطاء (ERROR).
10. **الدقة الطبية أولاً:** أي رقم أو جرعة أو معلومة غير مؤكدة لا تُكتب.

## 3. `pack.json`

| الحقل | إلزامي | الوصف |
|---|---|---|
| `format` | ✅ | دائماً `"instaanki-pack"` |
| `formatVersion` | ✅ | دائماً `1` |
| `id` | ✅ | معرّف الحزمة: أحرف إنجليزية صغيرة وأرقام و`-` (مثل `cardio-basics-001`) |
| `version` | ✅ | رقم صحيح يبدأ من 1، ويزيد مع كل إصدار جديد للحزمة |
| `title` | ✅ | عنوان الحزمة |
| `language` | ✅ | `ar` أو `en` أو مثلاً `ar-EN` |
| `createdAt` | ✅ | `YYYY-MM-DD` |
| `reels` | ✅ | قائمة معرّفات الريلات بترتيب العرض. كل معرّف = مجلد في `reels/` |
| `description` | | وصف |
| `author` | | المؤلف |
| `tags` | | تاغات عامة للحزمة |
| `licenses` | | مصدر الصور ورخصتها: `{ "files", "license", "source", "attribution" }` |

```json
{
  "format": "instaanki-pack",
  "formatVersion": 1,
  "id": "cardio-basics-001",
  "version": 1,
  "title": "أساسيات القلب",
  "language": "ar",
  "createdAt": "2026-11-07",
  "reels": ["cardio-heart-chambers-001"]
}
```

## 4. `reel.json`

### 4.1 الحقول الرئيسية

| الحقل | إلزامي | الوصف |
|---|---|---|
| `id` | ✅ | معرّف ثابت للريل = اسم مجلده |
| `revision` | ✅ | يبدأ من 1، ويزيد عند أي تصحيح |
| `title` | ✅ | عنوان الريل |
| `language` | ✅ | لغة التعليق |
| `duration` | ✅ | مدة الصوت بالثواني، بفارق لا يتجاوز ±0.5 ثانية عن الملف الفعلي. المستحسن 60–90 ثانية |
| `audio` | ✅ | مسار ملف الصوت |
| `transcript` | ✅ | مسار ملف توقيت الكلمات |
| `tags` | ✅ | تاغات هرمية بالإنجليزي: `cardiology/anatomy` |
| `images` | ✅ | الصور (§4.2) |
| `regions` | ✅ | المناطق (§4.3) |
| `segments` | ✅ | المقاطع (§4.4) |
| `cues` | ✅ | أحداث الـ timeline (§4.5) |
| `questions` | ✅ | الأسئلة (§4.6) |
| `pretest` | | معرّف سؤال `mcq` أو `truefalse` يُعرض قبل الفيديو أول مرة |
| `recap` | | `{ "segments": [...] }`: المقاطع التي تُعرض كملخّص سريع |
| `related` | | `[{ "reel": "...", "relation": "confusable" \| "prerequisite" \| "followup" }]` |
| `remediates` | | للحزم العلاجية: معرّفات الريلات التي يعالجها هذا الريل |

**حقول إضافية:** أي حقل غير موثّق يُرفض، إلا إذا بدأ اسمه بـ `x-` (مثل `"x-note"`). هذا يمنع الأخطاء الإملائية في أسماء الحقول.

### 4.2 الصور: `images`

```json
"images": {
  "heart": { "src": "img/heart.svg", "width": 1000, "height": 1200, "alt": "مخطط حجرات القلب" }
}
```

- **المفتاح** (`heart`) هو ما تشير إليه المناطق والـ cues.
- **`width` و`height`** يساويان أبعاد الـ `viewBox` في SVG، أو أبعاد الصورة بالبكسل.

### 4.3 المناطق: `regions`

```json
"regions": {
  "left-ventricle": { "image": "heart", "svgId": "left-ventricle", "label": "البطين الأيسر", "quiz": true },
  "lesion":         { "image": "xray",  "rect": { "x": 0.52, "y": 0.31, "w": 0.18, "h": 0.12 }, "label": "الآفة" }
}
```

| الحقل | الوصف |
|---|---|
| `image` | مفتاح الصورة |
| `label` | الاسم الذي يظهر على الشاشة ويُسأل عنه |
| `aliases` | أسماء بديلة مقبولة (مثلاً `["الشريان الأورطي"]`) |
| `quiz` | `true` (الافتراضي) = تُستخدم في صيغتي "شنو هذا؟" و"وين هو؟" |
| **شكل واحد فقط من:** | |
| `svgId` | معرّف عنصر داخل SVG (**المفضّل**) |
| `rect` | `{x, y, w, h}` نسبية من 0 إلى 1 |
| `circle` | `{cx, cy, r}`، ونصف القطر `r` نسبة من عرض الصورة |
| `polygon` | `[[x, y], ...]` ثلاث نقاط على الأقل، نسبية |

- المفتاح `full` محجوز لمعنى "الصورة كاملة".
- **3 مناطق `quiz` أو أكثر لكل ريل** حتى تعمل الصيغ التلقائية جيداً.

### 4.4 المقاطع: `segments`

```json
"segments": [
  { "id": "intro",    "start": 0.0,  "end": 4.1,   "importance": "minor", "summary": "مقدمة" },
  { "id": "chambers", "start": 4.1,  "end": 13.95, "importance": "key",   "summary": "أربع حجرات: أذينان يستقبلان وبطينان يضخان" }
]
```

- المقاطع **مرتّبة وغير متداخلة**، والأفضل أن تغطي الريل كاملاً.
- **`importance`:**
  - `key`: المعلومة الأساسية التي يُسأل عنها. يُعرض بالسرعة العادية، ويدخل في الملخّص ووضع الامتحان.
  - `normal`: شرح داعم.
  - `minor`: مقدمة وربط وختام. يُسرَّع تلقائياً.
- **مقطع `key` واحد على الأقل** لكل ريل.
- **`summary`:** جملة قصيرة تلخّص المقطع، وتظهر في البحث والملخّصات.

### 4.5 أحداث الـ timeline: `cues`

**قواعد عامة:**
- كل cue فيه `t` (وقت البداية) و`type`. ما فيه `until` يختفي عند ذلك الوقت.
- رتّب الـ cues حسب `t`.
- **أول cue** يجب أن يكون `show` عند `t: 0`.
- كل المناطق المشار إليها يجب أن تكون على الصورة المعروضة في ذلك الوقت.

| النوع | الحقول الإلزامية | حقول اختيارية |
|---|---|---|
| `show` | `image` | `transition`: `cut` / `fade` / `slide` · `duration` (0–3 ث) |
| `camera` | `target` (منطقة أو `full`) | `zoom` (1–6) · `duration` (0–5 ث) · `ease`: `linear` / `in` / `out` / `inOut` |
| `spotlight` | `target` (منطقة أو قائمة مناطق) · `until` | `dim` (0–1، شدة التعتيم) · `shape`: `auto` / `circle` / `rect` |
| `label` | `region` · `until` | `text` (بدل الـ label الافتراضي) · `position`: `auto` / `top` / `bottom` / `left` / `right` |
| `arrow` | `from` · `to` · `until` | |
| `text` | `text` · `until` | `position`: `top` / `center` / `bottom` · `style`: `title` / `keyword` / `formula` / `note` |
| `pulse` | `region` | |

```json
{ "t": 0,     "type": "show", "image": "heart", "transition": "fade", "duration": 0.6 },
{ "t": 0,     "type": "camera", "target": "full" },
{ "t": 7.12,  "type": "spotlight", "target": ["right-atrium", "left-atrium"], "until": 10.78, "dim": 0.7 },
{ "t": 7.12,  "type": "label", "region": "right-atrium", "until": 10.78 },
{ "t": 24.17, "type": "camera", "target": "right-ventricle", "zoom": 1.7, "duration": 0.9, "ease": "inOut" },
{ "t": 28.92, "type": "arrow", "from": "right-ventricle", "to": "pulmonary-trunk", "until": 32.09 }
```

**نصائح للإخراج:**
- **حركة كاميرا عند كل مفهوم جديد،** مع spotlight على نفس المنطقة بنفس اللحظة.
- **`zoom` بين 1.3 و2.2** عادةً. التقريب الأكبر يضيّع السياق.
- **لا تزدحم الشاشة:** تسميتان أو ثلاث بنفس الوقت كحد أقصى.
- **ارجع لـ `full`** عند الانتقال لفكرة عامة أو في الختام.

### 4.6 الأسئلة: `questions`

**حقول مشتركة:**

| الحقل | إلزامي | الوصف |
|---|---|---|
| `id` | ✅ | معرّف فريد داخل الريل (`q-...`) |
| `type` | ✅ | `mcq` / `truefalse` / `cloze` / `order` / `case` / `compare` / `teachback` |
| `explain` | ✅ | معرّف المقطع (أو قائمة مقاطع) التي تشرح الجواب |
| `level` | | `recall` / `understand` / `apply` |
| `explanation` | | تعليل قصير يظهر بعد الجواب |

**الخيارات الخاطئة:** معقولة ومن نفس المجال، بلا "كل ما سبق" ولا "لا شيء مما سبق". التطبيق يخلط ترتيب الخيارات بنفسه، فاكتب الصحيح في أي موقع وحدّده بـ `answer` (يبدأ العد من 0).

#### `mcq`: اختيار من متعدد
```json
{ "id": "q-why-thick", "type": "mcq", "level": "understand", "explain": "lv-wall",
  "stem": "لماذا جدار البطين الأيسر أسمك من جدار البطين الأيمن؟",
  "options": ["لأنه يضخ ضد ضغط الدورة الجهازية العالي", "لأنه يستقبل كمية دم أكبر من الأيمن",
              "لأنه يضخ الدم إلى الرئتين", "لأنه يحتوي على صمامين بدل صمام واحد"],
  "answer": 0 }
```
من 3 إلى 5 خيارات.

#### `truefalse`: صح/خطأ
```json
{ "id": "q-tf-rv-aorta", "type": "truefalse", "explain": "right-side",
  "statement": "البطين الأيمن يضخ الدم إلى الأبهر.", "answer": false,
  "explanation": "البطين الأيمن يضخ إلى الشريان الرئوي. الأبهر يخرج من البطين الأيسر." }
```
اجعل نصف العبارات تقريباً خاطئة، والخطأ يكون في معلومة واحدة واضحة.

#### `cloze`: أكمل الجملة (صوتي)
```json
{ "id": "q-cloze-aorta", "type": "cloze", "explain": "left-side",
  "from": 41.87, "cut": 44.57, "resume": 45.26,
  "sentenceText": "والبطين الأيسر يضخّه إلى ____، ومنه إلى كل الجسم.",
  "options": ["الأبهر", "الشريان الرئوي", "الوريد الأجوف", "الأذين الأيسر"], "answer": 0 }
```

| الحقل | المعنى |
|---|---|
| `from` | بداية الجملة في الصوت |
| `cut` | بداية الكلمة المخفية، **مطابقة لـ `s` في الـ transcript** |
| `resume` | نهاية الكلمة المخفية |
| `sentenceText` | نسخة مكتوبة فيها `____` (تُستخدم إذا كان الجوال صامتاً) |

#### `order`: رتّب
```json
{ "id": "q-order-flow", "type": "order", "explain": ["right-side", "left-side"],
  "prompt": "رتّب مسار الدم من لحظة رجوعه من الجسم حتى يخرج للجسم مرة ثانية",
  "items": ["الوريد الأجوف", "الأذين الأيمن", "البطين الأيمن", "الشريان الرئوي",
            "الرئتان", "الأذين الأيسر", "البطين الأيسر", "الأبهر"] }
```
العناصر **بالترتيب الصحيح** (من 3 إلى 8)، والتطبيق يخلطها.

#### `case`: حالة سريرية
```json
{ "id": "q-case-htn", "type": "case", "level": "apply", "explain": "clinical",
  "vignette": "رجل عمره 58 سنة عنده ارتفاع ضغط دم غير مضبوط منذ 15 سنة…",
  "stem": "أي حجرة يُتوقع أن جدارها هو الذي ازداد سماكةً؟",
  "options": ["البطين الأيسر", "البطين الأيمن", "الأذين الأيمن", "الأذين الأيسر"], "answer": 0 }
```
السؤال يطبّق المعلومة على موقف جديد، ولا يكرّر جملة من الفيديو.

#### `compare`: فرّق بينهما
```json
{ "id": "q-cmp-crohn", "type": "compare", "explain": "pattern",
  "prompt": "أيهما فيه skip lesions؟",
  "image": "colon", "otherReel": "gi-ulcerative-colitis-001", "otherImage": "colon",
  "answer": "this" }
```
`answer`: `this` (صورة هذا الريل) أو `other`. الريل الآخر يجب أن يكون في نفس الحزمة أو موجوداً مسبقاً في التطبيق، والأفضل إضافته في `related` بعلاقة `confusable`.

#### `teachback`: اشرح بصوتك
```json
{ "id": "q-teach-wall", "type": "teachback", "explain": "lv-wall",
  "prompt": "اشرح بصوتك: ليش جدار البطين الأيسر أسمك من الأيمن؟",
  "keywords": [["ضغط", "مقاومة"], ["الجهازية", "الجسم", "الدورة الكبرى"]], "minHits": 2 }
```
`keywords` مجموعات من المترادفات. الجواب صحيح إذا وُجدت كلمة من `minHits` مجموعات على الأقل.

#### صيغ لا تحتاج كتابة
**`identify` (شنو هذا؟)** و**`locate` (وين هو؟)** يولّدهما التطبيق من المناطق التي فيها `quiz: true`، فلا تكتبهما في `questions`.

## 5. `transcript.json`

```json
{
  "words": [
    { "w": "خلّينا", "s": 0.50, "e": 1.11 },
    { "w": "البطين", "s": 24.17, "e": 24.86, "key": true }
  ],
  "sentences": [ { "s": 0.50, "e": 3.74 } ]
}
```

- **`words`** كل كلمة كما تُنطق، مع بدايتها `s` ونهايتها `e` بالثواني، ومرتّبة زمنياً.
- **`key: true`** للمصطلحات المهمة؛ تتلوّن في الترجمة المتزامنة.
- **`sentences`** اختيارية، وتساعد في `cloze` وحذف السكتات.
- **مصدر التوقيت:** أداة TTS التي تعطي توقيت الكلمات مباشرة، أو forced alignment بعد التوليد (مثلاً Whisper مع word timestamps).

## 6. مواصفات الملفات

| النوع | الصيغة | المواصفات |
|---|---|---|
| الصوت | **Opus** (`.opus`، المفضّل) أو `.m4a` أو `.mp3` | أحادي (mono)، 32–48 kbps، أقل من 1 MB، 60–90 ثانية، صوت واضح بإيقاع هادئ |
| المخططات | **SVG** | `viewBox` يطابق `width`/`height`، المجموعات بمعرّفات، بدون نصوص أو سكربتات |
| الصور الحقيقية | **WebP** | أطول ضلع 2048 px أو أقل، والحجم 1.5 MB أو أقل |
| الحزمة | ZIP | أقل من 50 MB. الأكبر تُقسَّم |

**ألوان المخططات:** استخدم ألواناً واضحة على الخلفيات الفاتحة والداكنة، وحدوداً (stroke) واضحة لكل منطقة. اتّبع اتفاقيات الطب المعروفة: الأحمر للدم المؤكسَج، والأزرق لغير المؤكسَج.

## 7. الحد الأدنى لكل ريل

- [ ] مدة 60–90 ثانية، وفكرة واحدة واضحة.
- [ ] 3 مناطق `quiz` أو أكثر بأسماء دقيقة.
- [ ] مقطع `key` واحد على الأقل.
- [ ] سؤال `pretest` (mcq أو truefalse).
- [ ] سؤال `mcq` واحد على الأقل غير الـ pretest، يُسأل بعد الفيديو.
- [ ] عبارتان `truefalse` أو أكثر.
- [ ] `cloze` واحد على الكلمة المفتاحية.
- [ ] `case` واحد إذا كان للمعلومة تطبيق سريري.
- [ ] كل سؤال له `explain` صحيح.
- [ ] المصطلحات المهمة عليها `key: true` في الـ transcript.
- [ ] مجموع الأسئلة + مناطق quiz لا يقل عن 6 (حتى لا تتكرر المراجعات).

## 8. خطوات الإنتاج (لـ GPT)

1. **النص:** اكتب التعليق مقسّماً لمقاطع (`intro` ← المفاهيم ← تطبيق سريري ← خلاصة)، وحدّد أهمية كل مقطع. اجعل الجمل قصيرة.
2. **الصور:** ارسم المخطط SVG بالكود، وكل جزء مهم في `<g id="...">`. بدون نصوص.
3. **المناطق:** عرّف `regions` بـ `svgId` والـ `label` الدقيق.
4. **الصوت:** ولّد الصوت بأداة TTS، ثم حوّله إلى Opus أحادي.
5. **التوقيت:** استخرج توقيت كل كلمة وأنشئ `transcript.json`.
6. **حدود المقاطع:** احسبها من توقيت الجمل.
7. **الـ cues:** لكل مفهوم ابحث عن الكلمة في الـ transcript، واجعل `t` = `s` تلك الكلمة.
8. **الأسئلة:** اكتبها مع `explain` لكل سؤال، واجعل `cut`/`resume` في `cloze` من الـ transcript مباشرة.
9. **الحزمة:** اكتب `pack.json`، ثم اضغط المجلد بحيث يكون `pack.json` في جذر الـ ZIP.
10. **التحقق:**
    ```bash
    pip install jsonschema        # مرة واحدة
    python3 tools/validate_pack.py cardio-basics-001-v1.zip
    ```
    إذا ظهرت `ERROR`، أصلحها وأعد التحقق. والـ `WARNING` راجعها.
11. **التسليم:** سمِّ الملف `<pack-id>-v<version>.zip`، وارفعه في GitHub Release بوسم `pack-<pack-id>-v<version>`، أو سلّمه للاستيراد اليدوي.

## 9. الإصدارات والتحديث

| الحالة | ماذا تفعل |

| ريل جديد | `id` جديد |
| تغيير جذري في الصيغة | سيرتفع `formatVersion`، وستُوثَّق التغييرات هنا |
