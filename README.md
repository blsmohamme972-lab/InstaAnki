# InstaAnki

تطبيق أندرويد شخصي يدمج تجربة **الريلز** مع **التكرار المتباعد** (مثل أنكي) بشكل مخفي، لتحويل عادة مشاهدة الفيديوهات القصيرة إلى تعليم طبي.

- تسكرول مثل إنستغرام، وكل ريل يدخل الجدولة تلقائياً **بدون أزرار تقييم**.
- **المراجعة تبدأ بسؤال** بصيغ متنوعة (صح/خطأ، شنو هذا؟، وين هو؟، أكمل الجملة، حالة سريرية…)، والفيديو يُعاد فقط عند الخطأ، ومن المقطع الذي يشرح الجواب.
- **الريل ليس MP4:** صور (SVG) + صوت + timeline لحركة الكاميرا والإضاءة متزامنة مع الصوت. يصنعها GPT في حزمة ZIP.
- **كل شيء محلي**، و**التحديث جزئي وتلقائي** من GitHub بدون إعادة تثبيت.

## التحقق من حزمة

```bash
pip install jsonschema
python3 tools/validate_pack.py examples/sample-pack          # مجلد
python3 tools/validate_pack.py cardio-basics-001-v1.zip       # أو ZIP
```

> في حزمة المثال، الصوت صامت (placeholder)، والمخطط تبسيطي للتوضيح فقط.
