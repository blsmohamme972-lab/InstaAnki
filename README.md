# InstaAnki

An English-only personal Android learning app concept combining a short-form lesson feed with automatic spaced repetition.

## Current project material

- [Fixed surgical tag registry](taxonomy/registry.v1.json)
- [Tagging policy](taxonomy/README.md)
- [Question annotation schema](taxonomy/annotation.schema.json)
- [Synthetic annotation examples](taxonomy/examples.json)
- [Visual production rules](docs/visual-production-rules.md)

The three primary specialties are **Cardiac Surgery**, **Thoracic Surgery** and **Vascular Surgery**. The same canonical tags are reused across books and lessons.

The repository currently contains specifications and taxonomy data. These files do not constitute an implemented Android app, a processed book or generated lesson media.
